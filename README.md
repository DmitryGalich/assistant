# Assistant

Chat bot for businesses based on LLMs.

## Features:
- Ability of adding new info about products
- Communicating with customers for helping to with products choice
- Sending notifications about new orders

## Components
- Open source LLM
- Tool for connecting with social media
  - Telegram
  - Whatsapp
  - Instagram
- Database for storing information about users and their preferences
- Web interface for managing the bot
